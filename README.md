### 🔹 [University Admission Policy Assistant Chatbot](https://github.com/abdullahsoomro61873/University-Admission-Policy-Assistant-Chatbot)

A RAG-based chatbot that answers admission questions for Mohammad Ali Jinnah University using the official policy document. It retrieves the relevant policy sections first and only then generates an answer, so responses stay grounded instead of hallucinated. It runs a local small language model, with no external API needed.

### 🔹 [Theft Detection System (IoT, Raspberry Pi)](https://github.com/abdullahsoomro61873/Python_Theft-Detection-System-as-an-IoT-application-using-a-Raspberry-Pi)

A smart security system built on a Raspberry Pi that combines sensors, a camera, and Wi-Fi. It has active and standby modes, uses piezoelectric sensors to trigger an alarm on theft, and captures images with the camera for more detail on the incident.
